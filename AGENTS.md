# Agents

All agent instructions for this repository live in **CLAUDE.md** — read it
first, whatever model or tool you are. The short version: `sim/` is pure and
deterministic, the sim never writes prose, content is data, GDScript is
strictly typed, and `./scripts/check.sh` must be green before you claim
anything works. The build order lives in ROADMAP.md; do not build ahead of it.
